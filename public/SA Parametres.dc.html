Où trouver ces clés ?
  1. Console Google Cloud : un projet, avec les API « My Business Account Management », « My Business Business Information », « Google Ads API », « Google Analytics Admin » et « Google Analytics Data » activées.
  2. Écran de consentement OAuth : publié « En production » (en « Test », le jeton expire au bout de 7 jours).
  3. Identifiants → ID client OAuth de type « Application Web », avec l’URI de redirection https://developers.google.com/oauthplayground : l’ID et la clé secrète vont ici.
  4. OAuth Playground (réglages ⚙ → « Use your own OAuth credentials ») : autoriser les trois accès {{ gScopes }} avec le compte Google qui gère les fiches, Ads et Analytics, puis « Exchange authorization code for tokens » : le Refresh token va ici.
  5. Les accès que Google doit accorder : fiches (formulaire « Business Profile API »), Google Ads (niveau « Explorer » dans la console Google Cloud). Le détail : docs/GOOGLE.md.
